# Memory-Vault
Academic Resource &amp; Learning Platform

**Problem Statement**

Students often have study materials, notes, previous-year questions, and resources scattered across multiple platforms. Finding relevant content, revising important topics, and understanding previous-year question patterns can be time-consuming.

**Proposed Solution**

Memory Vault is an academic resource management platform that centralizes study materials and provides intelligent search, revision prioritization, previous-year question analysis, and AI-assisted learning tools.
